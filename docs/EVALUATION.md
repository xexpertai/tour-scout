# Evaluation: does the app do what it says?

Tour Scout makes four promises about every plan: **every number is cited**, **every route is drivable**,
**openers fit the act's size (or say they don't)**, and **the agent only proposes changes it earned from its
own Qloo requests**. A fifth safeguard, the **guard**, withholds model text that overclaims. This page checks
each one with a script you can run yourself, offline, in a few seconds:

```sh
npm ci && npm run eval        # no keys, no Qloo or model calls, no network
```

`scripts/evaluate.mts` reads the three demo runs captured from live Qloo data on 7 Oct 2026
(`public/presets/*.json`) and the red-team sentences in `docs/eval/`. `npm test` checks that the table
below is exactly what the script prints today.

**What this does not show:** whether the cities are the *right* ones for an act's ticket sales. Only real
tours can show that. The small check against past show lists was inconclusive ([BACKTEST.md](BACKTEST.md)),
and the app has not yet been tried by real acts.

## How the guard sets were made

- **The first set** (`docs/eval/guard-cases.json`, 82 sentences) was written by hand after the guard, as
  sentences a model might write for the three demo plans. On its first scoring the guard withheld
  **32 of 42** overclaims and wrongly withheld **0 of 40** ordinary sentences. The 10 misses were then fixed
  in `src/lib/guard.ts` (new phrasings for income, named religions and sexual identities, head-count
  forecasts, single room sizes, "market … to women", "most of these listeners are …", "one fan", and
  initials such as "S.G." that broke a sentence match). So that set is now a regression test, not a measure.
- **The held-out set** (`docs/eval/guard-holdout.json`, 50 sentences) was written and committed *before*
  those fixes, and scored only after them. Its result is the fairer estimate of how the guard handles
  phrasing it has not seen: it catches **about half** of unseen overclaims. The misses are listed above and
  have not been fixed, so the number stays an honest held-out measure.
- Both sets were written by the builder, not by an independent reviewer, and they are small. Treat them as a
  floor on what the guard misses, not a certificate.

**What that means for a plan:** the guard is the second line, not the first. The model's instructions carry
the same rules; every value on screen still comes from Qloo with its request; AI text is labelled AI and
cites its requests; and the plan tells you how many statements were withheld and why.
